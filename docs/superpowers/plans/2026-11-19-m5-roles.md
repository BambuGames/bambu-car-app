# M5 Roller Uygulama Planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Kredi düşüren ilk işlemeyi yalnız galeri sahibi başlatır. Personel bunu stüdyoda görür, araç listesi de işlenmeyi bekleyen araçları gösterir.

**Architecture:**
- **Sunucu kuralı:** tek kural `public.start_processing` içindedir. Kredi düşecekse ve çağıran sahip değilse fonksiyon `not_owner` hatası verir. `process-vehicle` bu hatayı `403 { error: 'not_owner' }` olarak döndürür.
- **Stüdyo:** personel ücretlendirilmemiş araçta "Bearbeiten" yerine bir not görür.
- **Araç listesi:** çekimi bitmiş ve yüklemesi tamamlanmış araçlarda "İşlenmeyi bekliyor" etiketi çıkar. Etiketin kararı saf bir yardımcıdan gelir.

**Tech Stack:** Supabase (Postgres plpgsql, Edge Functions/Deno), Expo SDK 58 / React Native 0.88, jest, pgTAP, node:test.

**Spec:** `docs/superpowers/specs/2026-11-19-m5-roles-design.md` (üst: `docs/superpowers/specs/2026-11-03-pilot-mvp-design.md` bölüm 4)

## Global Constraints

- **Kural:**
  - Kredi düşecekse (araç için `credit_ledger`'da `reason = 'vehicle'` satırı yoksa) ve çağıran sahip değilse `start_processing` şu hatayı verir: `raise exception 'not_owner' using errcode = '42501'`.
  - Bu durumda kredi düşmez ve hiçbir fotoğraf kuyruğa girmez.
  - Sahiplik kontrolü bakiye kontrolünden önce yapılır. Böylece personel kredi durumunu öğrenmez.
  - Araç bir kez ücretlendirildiyse personel bugünkü gibi işler.
- **Cevap:** `process-vehicle` `403 { error: 'not_owner' }` döndürür. Başka galerinin aracı için bugünkü `403 { error: 'not_member' }` aynen kalır.
- **Metinler** (birebir):
  - `studio.ownerProcesses` ve `studio.errors.not_owner`:
    - de: "Dieses Fahrzeug verarbeitet der Inhaber der Galerie."
    - tr: "Bu aracı galeri sahibi işleyecek."
    - en: "The gallery owner processes this vehicle."
  - `vehicles.waitingForProcessing`:
    - de: "Wartet auf Verarbeitung"
    - tr: "İşlenmeyi bekliyor"
    - en: "Waiting for processing"
  - Her yeni anahtar üç dil dosyasına girer ve `src/lib/i18n.test.ts` geçer.
- **Liste etiketi koşulu:** `status === 'shooting'`, `exteriorDone === EXTERIOR_SLOTS.length` ve `pendingUploads === 0`. Listenin sırası değişmez.
- **Değişmeyenler:** paylaşım, dışa aktarma, ilan metni ve rapor okuma personelde kalır. Yeni yerel paket ve yeniden derleme yoktur.
- **Arayüz:**
  - /no-slop-ui geçerlidir. Mevcut `Notice` ve `Button` kullanılır.
  - React Compiler kuralları: hook bağımlılıkları tetikleyici olarak kullanılmaz; render içinde `Date.now()` okunmaz; ref'lere yalnız effect ve callback içinde yazılır.
- **Kullanıcının kuralları:**
  - `git commit` çalıştırılmaz.
  - `supabase db reset` ve `supabase stop --no-backup` yok. Göç `npx supabase migration up` ile uygulanır.
  - Buluta gönderim ve fonksiyon yüklemesi yok.
  - Yerel Supabase `npm run db:start` ile açılır, iş bitince `npx supabase stop` ile kapatılır.
  - Testler sahte OpenAI ile çalışır; `checkLocalAi.mjs` korumasını atlama.
  - `supabase/functions/.env` değerleri yazdırılmaz.
  - Simülatör: iPhone 17, Metro yalnız 8082'de ve CI modu kapalı. 8081, `melocaly-*` kapsayıcıları ve iPhone 16 Pro Max'e dokunulmaz.
  - Xcode komutları `DEVELOPER_DIR=/Users/egemenderbedek/Downloads/Xcode-26.6.app/Contents/Developer` ile çalışır.
  - Test hesapları seed'dedir: `owner@bambu.test`, `staff@bambu.test` (şifre `supabase/seed.sql`'de).

## Review Focus

1. **Kredisi sıfır olan galeride personel:** "kredi yok" değil, `not_owner` alır. Kredi durumu personele sızmaz. → Task 1, `staff cannot start the first, charged processing` (bakiye 0 iken).
2. **Başka galerinin aracı:** yine `not_member` alır; yeni 403 eşlemesi onu yutmaz. → Task 1, mevcut `answers 403 for another gallery's vehicle`; Task 2, `a 403 without not_owner stays not_member`.
3. **Ödenmiş araçta personel:** rötuş, plaka ve yeniden işleme bozulmaz. → Task 1, `staff can re-render a paid vehicle` ve `staff re-render does not charge`.
4. **Önbellekteki rol eski ya da üyelik henüz yüklenmemiş:** ekran yanlış düğme gösterse bile sunucunun `not_owner` cevabı aynı not olarak görünür; uygulama çökmez. → Task 2, `ownerMustProcess` testleri ve `a 403 with not_owner maps to not_owner`.
5. **Yarım yüklenmiş araç:** bir fotoğraf hâlâ telefondaysa ya da bir dış açı eksikse "İşlenmeyi bekliyor" çıkmaz. → Task 3, `still uploading stays shooting` ve `missing an exterior angle stays shooting`.
