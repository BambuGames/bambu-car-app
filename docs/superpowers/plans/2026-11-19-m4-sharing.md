# M4 Paylaşım Uygulama Planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Galeri bir aracı tek dokunuşla paylaşabilir: düzen A'daki afiş, seçili stüdyo fotoğrafları ve ilan metni sistemin paylaşım menüsü üzerinden WhatsApp, Instagram ve diğer uygulamalara gider. Afişte galerinin telefon ve WhatsApp numarası yer alır.

**Architecture:**
- **Galeri iletişim bilgisi:** Galeriye iki iletişim sütunu eklenir. Sahip bunları galeri ayarlarında girer.
- **Afiş içeriği:** Afişin metin içeriği saf bir modülde hesaplanır ve test edilir.
- **Afiş çizimi:** Skia ile telefonda ekran dışı çizilir ve JPEG olarak yazılır.
- **Paylaşım:** Yeni bir paylaş ekranı afişi, fotoğrafları ve metni `react-native-share` ile tek seferde sistem paylaşım menüsüne verir. Metin aynı anda panoya da kopyalanır.

**Tech Stack:** Expo SDK 58 / React Native 0.88, `@shopify/react-native-skia` 2.14, `react-native-share` 12.3.1, `@expo-google-fonts/source-sans-3` 0.4.2, `expo-clipboard`, Supabase (Postgres + RLS), jest, pgTAP.

**Spec:** `docs/superpowers/specs/2026-11-19-m4-sharing-design.md` (üst: `docs/superpowers/specs/2026-11-03-pilot-mvp-design.md`, M3: `docs/superpowers/specs/2026-11-18-m3-vehicle-details-listing-design.md`)

**Files:**

- Modify: `apps/mobile/src/locales/{de,tr,en}.json` (`share.poster.*`)

**Interfaces:**
- Consumes:
  - `Vehicle` (`src/domain/vehicle.ts`)
  - `Listing` (`src/local/listings.ts`)
  - `GalleryBranding` (Task 1)
  - `Language` (`src/domain/vehicleData.ts`)
- Produces:
  - `type PosterFormat = '4:5' | '9:16'`
  - `POSTER_SIZE: Record<PosterFormat, { width: number; height: number }>`: `{ '4:5': { width: 1080, height: 1350 }, '9:16': { width: 1080, height: 1920 } }`
  - `type PosterModel = { title: string; facts: string[]; price: string; priceNote: string | null; location: string | null; contact: { phone: string | null; whatsapp: string | null } | null }`
  - `posterModel(v: Vehicle, l: Listing | null, g: Pick<GalleryBranding, 'phone' | 'whatsapp'>, lang: Language, t: TFunction): PosterModel`
    - **title:** marka + model + varyant.
    - **facts:** ilk tescil (`MM/YYYY`), km, yakıt etiketi, şanzıman etiketi. Bu sırayla ve yalnız değeri olanlar.
    - **priceNote:** KDV ve garanti, " · " ile birleştirilir; ikisi de yoksa `null`.
    - **contact:** iki numara da yoksa `null`.
  - `fitTitle(text: string, maxWidth: number, maxLines: number, measure: (s: string) => number): string[]`. Kelimelerle sarar; son satıra sığmayanı "…" ile kısaltır.
  - `fitFacts(items: string[], maxWidth: number, separator: string, measure: (s: string) => number): string[]`. Satıra sığmayan öğeleri sondan atar.

- [ ] **Adım 1: Başarısız testleri yaz**

```ts
test('posterModel builds the band from vehicle, listing and gallery', () => {
  const m = posterModel(crossland, listing({ priceEur: 17990, vatDeductible: true, warrantyMonths: 12, location: 'Berlin' }),
    { phone: '+49 30 1234567', whatsapp: '+49 170 1234567' }, 'de', t);
  expect(m.title).toBe('Opel Crossland 1.2 130 AT6 ESSENTIAL');
  expect(m.facts).toEqual(['07/2024', '45.004 km', 'Benzin', 'Automatik']);
  expect(m.price).toBe('17.990 €');
  expect(m.priceNote).toBe('MwSt. ausweisbar · 12 Monate Garantie');

test('posterModel skips missing facts and falls back to Preis auf Anfrage', () => {

  expect(m.facts).toEqual(['Diesel']);
  expect(m.price).toBe('Preis auf Anfrage');
  expect(m.priceNote).toBeNull();
});

test('posterModel has no contact line when the gallery has no numbers', () => {

test('fitTitle wraps to two lines and ends with an ellipsis', () => {

test('fitFacts drops items from the end until the line fits', () => {
```
