# M0 Erken Denemeler Uygulama Planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tasarımın 14. bölümündeki dört denemeyi yapıp M1 ve M2 planlarının dayanacağı seçimleri `docs/m0-findings.md` dosyasında sabitlemek: mobil paket sürümleri, araç tespit modeli, şablon parametreleri, maske yöntemi ve plaka yöntemi.

**Architecture:** Denemeler uygulama koduna dokunmaz. Atılacak deneme kodu `spikes/` altında durur ve git'e girmez. Şablon üretici (Görev 1) kalıcıdır, çünkü M1'in şablonları bu araçla üretilecek; testleriyle birlikte `tools/templates/` altında yaşar. Her görev bulgular dosyasına kendi bölümünü ve "Kararlar" tablosuna kendi satırlarını yazar.

**Tech Stack:** Python 3.13 (numpy, OpenCV, trimesh, pytest; PyTorch ve Hugging Face transformers sadece denemelerde), Expo SDK 58 ve React Native 0.88 dev build, react-native-vision-camera v5, react-native-fast-tflite v3, EfficientDet-Lite (MediaPipe, Apache 2.0), Photoroom API, BiRefNet (MIT).

**Spec:** `docs/superpowers/specs/2026-11-03-pilot-mvp-design.md` (özellikle 6.2, 6.3, 7.2 ve 14)

**Plan sırası:** Bu plan dört planın ilkidir (M0, M1, M2, M3). Görev 1 ve 2 hemen başlar; Görev 3 ve 4 galeri fotoğrafları gelince başlar. M1 planı Görev 1–2'nin sonuçlarıyla yazılır ve Görev 3–4'ü beklemez. M2 planı Görev 3–4'ün sonuçlarına dayanır.

## Global Constraints

- Platform: iOS ve Android, ilk pilot sürümden itibaren birlikte.
- Dış fotoğraflar yatay ve 4:3 çekilir; varsayılan kamera ana kamera (1x), dar alan modunda ultra geniş kamera (0.5x).
- Aracı yandan çekmek için gereken boşluk: normalde yaklaşık 4–5 m, dar alan modunda yaklaşık 2–2,5 m.
- Şablon kamerası yaklaşık 1 m yükseklikte, telefon düz tutulmuş.
- Zorunlu dış açılar (8), yürüme sırasıyla: ön sol 45°, ön, ön sağ 45°, sağ yan, arka sağ 45°, arka, arka sol 45°, sol yan.
- Pilot kasa tipleri: sedan (Limousine), Kombi, SUV, hatchback; diğerleri için genel kutu.
- Kullanılan her kod, model ağırlığı ve veri setinin lisansı ticari kullanıma uygun olmalı. AGPL lisanslı Ultralytics YOLO kullanılmaz.
- Aracın pikselleri yeniden üretilmez; görüntü üreten AI kullanılmaz.
- Node.js 24 LTS (en az 24.3). Kurulu Node 25'i Expo SDK 58 ve React Native 0.88 desteklemez.
- Hesapları kullanıcı açar. API anahtarını `spikes/.env` dosyasına kullanıcı kendisi yazar.
- Galeri fotoğrafları galerinin izniyle kullanılır ve git'e girmez (`spikes/data/`).
- İnternetten indirilecek 3D model ve model ağırlıkları önce kaynak, lisans ve boyutuyla kullanıcıya sorulur.
- Commitleri kullanıcı atar. Her görev değişen dosyaların listesi ve önerilen bir commit mesajıyla biter; `git commit` çalıştırılmaz.
- Bir deneme sonucu tasarımla çelişirse kullanıcıya sorulur ve tasarım dökümanı onun cevabıyla güncellenir.

**Interfaces:**
- Produces: M1 uygulaması her şablon için `out/{bodyType}/{slot}_{mode}.json` ve `.svg` okur:
  ```json
  {"bodyType": "sedan", "slot": "front_left_45", "mode": "normal",
   "hfovDeg": 69.0, "cameraHeightM": 1.0, "pitchDeg": 0.0, "distanceM": 5.2,
   "box": [0.10, 0.33, 0.90, 0.70], "svg": "front_left_45_normal.svg"}
  ```
  `box` kadraja oranla `[x0, y0, x1, y1]` (0–1). `distanceM` kameranın aracın merkezine yatay uzaklığı. SVG `viewBox="0 0 1600 1200"` ve tek kapalı `<path>` içerir.
- Sabitler (`templates.py`):
  - `SLOTS = {"front_left_45": 45, "front": 0, "front_right_45": 315, "right": 270, "rear_right_45": 225, "rear": 180, "rear_left_45": 135, "left": 90}`: yürüme sırası; değer, aracın önünden aracın soluna doğru ölçülen kamera açısı (derece).
  - `MODES = {"normal": 69.0, "wide": 106.0}`: yatay görüş açısı (derece).
  - `FILL = 0.80` (yan ve çapraz açılarda araç kutusunun kadraj genişliğine oranı), `FILL_FRONT_REAR = 0.65` (`front` ve `rear`).
  - `IMAGE_SIZE = (1600, 1200)`, `CAMERA_HEIGHT_M = 1.0`.
- Araç koordinatları: +x aracın önü, +y aracın solu, +z yukarı; orijin aracın zemindeki merkezi.
- Fonksiyonlar (`templates.py`):
  - `load_car(path: str, forward: str, up: str, length_m: float) -> tuple[np.ndarray, np.ndarray]`: köşeler (N×3, metre) ve üçgenler (M×3). Model eksenlerini (`"+z"`, `"-x"` gibi) araç koordinatlarına çevirir, x–y'de merkezler, zemini z=0'a koyar, boyu `length_m` olacak şekilde ölçekler.
  - `project(points: np.ndarray, azimuth_deg: float, distance_m: float, hfov_deg: float) -> np.ndarray`: N×2 piksel.
  - `solve_distance(vertices: np.ndarray, azimuth_deg: float, hfov_deg: float, fill: float) -> float`
  - `silhouette(vertices: np.ndarray, faces: np.ndarray, azimuth_deg: float, distance_m: float, hfov_deg: float) -> np.ndarray`: 1200×1600 uint8 maske.
  - `to_svg_path(mask: np.ndarray) -> str`: `"M x y L ... Z"`.
  - `make_template(vertices: np.ndarray, faces: np.ndarray, body_type: str, slot: str, mode: str) -> tuple[dict, str]`: JSON sözlüğü ve SVG belgesi.
  - `generate(body_type: str, out_dir: str) -> None`: `body_types.json`'dan modeli yükler, 8 açı × 2 mod için dosyaları ve tüm silüetleri etiketli gösteren 4×4 `overview.png`'yi yazar. CLI: `python tools/templates/templates.py sedan`.

```python
V, F = box_car()  # trimesh.creation.box(extents=[4.7, 1.85, 1.45]), z 0..1.45 aralığına kaydırılmış

def test_point_ahead_projects_to_center():
    uv = project(np.array([[0.0, 0.0, 1.0]]), 45, 5.0, 69.0)
    assert np.allclose(uv, [[800, 600]], atol=0.5)

def test_front_left_45_front_on_image_left():
    uv = project(np.array([[2.35, 0, 0.7], [-2.35, 0, 0.7]]), 45, 6.0, 69.0)
    assert uv[0, 0] < 800 < uv[1, 0]

def test_side_distance_normal_mode():
    assert 4.0 <= solve_distance(V, 90, 69.0, 0.80) - 1.85 / 2 <= 4.6

def test_side_distance_wide_mode():
    assert 2.0 <= solve_distance(V, 90, 106.0, 0.80) - 1.85 / 2 <= 2.4

@pytest.mark.parametrize("slot,fill", [("front", 0.65), ("front_left_45", 0.80), ("left", 0.80)])
def test_box_width_matches_fill(slot, fill):
    meta, _ = make_template(V, F, "test", slot, "normal")
    assert abs((meta["box"][2] - meta["box"][0]) - fill) < 0.01

def test_svg_path_closed_and_inside_viewbox():
    _, svg = make_template(V, F, "test", "front_left_45", "wide")
    d = re.search(r'd="([^"]+)"', svg).group(1)
    assert d.startswith("M") and d.endswith("Z")
    nums = [float(n) for n in re.findall(r"-?\d+(?:\.\d+)?", d)]
    assert all(0 <= x <= 1600 for x in nums[0::2]) and all(0 <= y <= 1200 for y in nums[1::2])
```

- [ ] **Adım 5: `templates.py`'yi yaz**

Kamera, açısı θ olan noktada `(R·cosθ, R·sinθ, 1.0)` konumundadır ve aracın merkezine yatay bakar: ileri `(−cosθ, −sinθ, 0)`, sağ `(−sinθ, cosθ, 0)`, aşağı `(0, 0, −1)`. `fx = 800 / tan(hfov/2)`, `u = 800 + fx·x_c/z_c`, `v = 600 + fx·y_c/z_c`. `solve_distance` R'yi [araç taban köşegeninin yarısı + 0.3 m, 40 m] aralığında 40 adım ikiye bölme ile bulur; ölçtüğü değer, izdüşen köşelerin yatay yayılımının (`u_max − u_min`) `fill · 1600`'e eşitliğidir. Maske tüm üçgenlerin tek bir `cv2.fillPoly` çağrısıyla doldurulmasıdır. `box` maskeden `cv2.boundingRect` ile alınır. SVG, en büyük dış konturun `cv2.approxPolyDP(epsilon=1.0)` ile sadeleştirilmiş halidir.
